# qflarebot-plugin-broadcast

QQ 机器人「群发 + 定时发送」插件。把一条消息一次性推送到多个群聊，或按指定时间自动推送。

> 所有命令**只能在私聊（单聊 / c2c）**中使用，且发起者须为 **Bot 管理员**（面板「设置 → 权限」中维护的 openid 名单）。不在私聊、或非管理员时命令不命中（既无副作用也不回复）。

## 命令总览

| 命令 | 作用 |
| --- | --- |
| `/列表` | 查看 / 创建 / 覆盖群列表 |
| `/群发` | 立即向目标群推送消息 |
| `/定时` | 创建一次性定时推送（北京时间 月:日:时:分） |
| `/查定时` | 查看所有待执行的定时任务 |
| `/删定时` | 删除指定的定时任务 |
| `/删列表` | 删除一个群列表 |

前置/权限：所有命令声明 `scenes: ['c2c']` 且 `permission: 'bot_admin'`。

---

## 群列表

群列表是一组群会话 id 的集合，给群发 / 定时指定「发送到哪些群」。一个列表可被多个任务复用。

内置保留列表 **`@all`** 表示「所有群聊」。把机器人加入的**全部群 openid** 放进 `@all`，此后群发 / 定时不填群参数即默认发 `@all`（用 `/sid` 查群，或手动收集）。

> 平台 v2 API 无法从单聊枚举机器人加入的全部群，因此「所有群聊」需要管理员手动把完整的群 id 列表填进 `@all`。

### `/列表` 用法

```text
/列表                         列出所有列表名称及每个列表内的群个数
/列表 <列表名>                查看该列表内的所有群会话 id
/列表 <列表名> <群id…>        创建该列表；若已存在则整体覆盖（替换为给定群 id）
/删列表 <列表名>              删除一个列表
```

示例：

```text
/列表 公告群 123abc,456def,789ghi   创建/覆盖列表「公告群」，含 3 个群
/列表 公告群                       查看「公告群」内的群
/列表                            列出所有列表
/列表 @all 123abc,456def           把全部群写进 @all
/删列表 公告群                     删除列表「公告群」
```

默认前缀为 `/`（面板可改）；单聊或 @ 机器人时可不带前缀。

注意：`@all` 是不可删除的保留列表，只能通过 `/列表 @all <群id…>` 覆盖其内容。

## 群发（立即发送）

```text
/群发 <内容> [群id逗号隔开 | 列表名 | @all]
```

- `<内容>`：要发送的文本。
- 第二段（可选）：发送目标。可以是
  - 一行逗号隔开的**群会话 id**，如 `123abc,456def`；
  - 一个**列表名**，如 `公告群`；
  - `@all`（所有群聊）；
  - 不填则默认发 `@all`。

示例：

```text
/群发 今晚八点准时上线！
/群发 系统维护通知 公告群
/群发 活动开始啦 @all
/群发 仅对这几个群 123abc,456def
```

发送结果会回执：**成功 N / 失败 M**，并列出失败群及其原因。

> 受平台限制，一次事件内主动消息子请求上限 50、处理总时长 30 秒。单次发送群数默认限 50，超出部分会被截断并提示，请分批发送。可在插件配置项 `maxPerSend` 中调整。

## 定时发送（一次性）

```text
/定时 <月:日:时:分> <内容> [群id逗号隔开 | 列表名 | @all]
```

- **`<月:日:时:分>` 为北京时间**，`:` 分隔，依次为月、日、时、分。
  例：`10:15:09:30` 表示 **10 月 15 日 09:30（北京时间）**。
- 只支持**当年的时间**。若目标时间已过、或不在今年范围，会提示不可用。
- 任务为**一次性**：到点自动推送一次，随后任务被删除，不会重复。

示例：

```text
/定时 12:01:08:30 元旦快乐 公告群
/定时 12:31:18:00 跨年祝福 @all
/定时 10:15:09:30 会议提醒 123abc,456def
```

到点前可通过 `/查定时` 查看，`/删定时 <任务id>` 取消。

```text
/查定时
/删定时 3
```

### 定时时间校验规则

- 格式必须为 `月:日:时:分`（每位 1~2 位数字）。
- 月 1–12；日按当月天数与闰年校验；时 0–23；分 0–59。
- 目标时刻必须**严格晚于当前北京时间**，否则提示「时间已经过去」。
- 仅限今年：跨出当年的目标时间视作不可用。

## 配置项

在面板插件详情页可改：

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| `intervalMs` | 发送时每个目标群之间的间隔（毫秒），避免瞬间刷爆主动消息额度。0 表示不停顿。 | 500 |
| `maxPerSend` | 单次发送最多推送的群数。受 30 秒与 50 子请求限制；0 表示不限制。 | 50 |

---

## 配额与存储

- 列表与定时任务存 **D1**，写入只发生在管理员主动操作时（建 / 改列表、建 / 删任务），不随消息数增长。
- 内置一个每分钟 Cron Trigger 负责分发到期的定时任务，**只读不写**，到点任务发送后即删除，避免堆积。
- 不使用 KV 存储高频变化的数据，规避其每天 1000 次写的上限。
- 群发逐群发送并带间隔，受平台子请求上限与 30 秒处理时限约束，由 `maxPerSend` 兜底。

## 开发

插件源码在 `src/index.ts`。

```bash
npm run build     # 生成 dist/plugin.js + dist/manifest.json
npm run sync      # 生成并复制 manifest.json 到仓库根
npm run typecheck # tsconfig 校验类型
```

构建依赖 `@qqbot/sdk` 与 `@qqbot/plugin-cli`，二者需与 QFlareBot 源码仓库并排（`file:../QFlareBot/packages/*`）。
